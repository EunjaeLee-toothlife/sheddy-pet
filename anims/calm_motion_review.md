## 재현과 원본

내장 ImageGen으로 복장별 표정 시트 5장을 생성했다. 프롬프트는 `prompts/calm/`, 생성된 투명 시트와 원래 기준 몸체는 `sprites/raw/calm/`에 있다. 정확한 원본 해시와 얼굴 합성 좌표는 `anims/calm_faces.json`에 저장했다. 이미지 생성 CLI나 API 키는 사용하지 않았다.

`tools/compose_calm_motion.py`가 기존 몸체의 작은 얼굴 영역만 합성하며, 기존 할로윈·기념일 빌더에서도 같은 경로를 사용한다. PNG는 720/512 양쪽에, 영상은 투명 VP9로 출력했다. 타이밍은 각 `anims/*_loop.json`의 `holds`와 `repeats`로 재현한다. `encode_holds.py`를 사용할 때 해당 설정의 `fps`를 `--fps`로 전달한다.

검증 환경: macOS, Chrome headless, Python + NumPy/Pillow, libvpx-vp9 인코더·디코더를 포함한 FFmpeg. 시스템 FFmpeg에 libvpx가 없어 검증·인코딩에는 임시 imageio-ffmpeg 0.6.0 번들의 FFmpeg 7.1을 사용했다. 프로젝트 의존성이나 시스템 설치는 변경하지 않았다.
