# 고해상도 원본 재작업 검수

기념일 40종과 복장 변신 12클립, 총 52클립/832출력 프레임의 검수를 완료했다.

## 그림과 원본

- 40개 일반 모션과 6개 변신 이탈의 16포즈 검수 시트에서 복장, 표정, 소품, 정렬, 잘림을 확인했다. 변신 등장은 이탈의 픽셀 기준 역순이다.
- 크리스마스 회전의 빛, 세배의 치마, 모래성의 파도가 원본 칸 경계에 걸린 세 쌍은 여백을 넓혀 재생성했다. 눈사람·로봇·모래성은 바닥 소품으로 인한 좌우 쏠림을 보정했다.
- 내장 ImageGen 원본 368장: 1774×887 367장, 1773×887 1장. 실제 사용한 포즈 칸은 최소 886×887, 최대 축소 비율 0.843138이다. 기존 중립 접합점의 재사용은 별도 anchor 증빙으로 구분한다.
- `verify_native_motion.py` 전체 46상태 검사: 52클립/832프레임 통과. 원본 해시·실제 셀 해상도·확대 금지·픽셀 재현·512/720 RGBA·VP9 알파·기존 fps/holds·재생 시간·대기 및 공통 빛 접합점·변신 역순 검사 포함.
- `tools/test_native_sources.py` 3개 통과: 실제 원본 재현, 잘못된 해시/크기/확대 비율 차단, 원본 증빙 누락 차단.

## 실제 위젯

`node tools/widget_check.js --mode MODE --capture`를 모드별로 실행했다. 선택기, 전용 모션 재생, 대기 복귀, 두 사이클 유지, 숨김 정지, 말하기, 자동 선택, 모드 격리 및 URL 상태 검사를 포함한다.

| 모드 | 통과 | 관측 자동 재생 캐시 |
| --- | ---: | ---: |
| 크리스마스 | 9 | 3,814,905 B |
| 설날 | 9 | 4,057,368 B |
| 어린이날 | 9 | 3,973,848 B |
| 여름 | 9 | 3,557,215 B |

생성된 Pages 배포본에서 다음 두 명령도 각각 11항목 통과했다. 전체 실제 재생 검사는 58항목이다.

```sh
node tools/widget_check.js --mode-switch --page docs/index.html --capture
node tools/widget_check.js --mode-switch --fallback --page docs/index.html
```

6개 복장의 이탈→등장→말하기, 마이크 연결 유지, 연속 클릭 차단, 숨김 정지·재개, 영상 로드 실패 복구, ended 유실 복구, 숨김 중 선택 대기, 키보드 조작을 확인했다. 캐시는 모든 경로에서 기존 4MiB 상한을 지켰다.

## 배포와 비용

`tools/deploy_pages.py --require-reviewed`로 138개 런타임 클립의 검수 상태와 해시를 확인해 Pages 배포본을 생성했다. 이는 로컬 배포본 검증이며 원격 Pages 반영은 PR 병합 후다.

대상 52개 720 영상의 총 크기는 29,726,536 B에서 36,757,736 B로 약 23.7% 증가했다. 선명한 원본으로 바꾸면서 전송할 영상 크기는 늘었지만, 위젯은 기존 지연 로딩과 4MiB 캐시 상한을 유지한다. 원본 PNG는 위젯에서 로드하지 않는다.
