## 재검증과 한계

```sh
python tools/audit_animation_assets.py --report /tmp/animation-assets.json
python -m unittest discover -s tools -p test_animation_asset_audit.py
node tools/widget_hd720_check.js
```

Python은 Pillow/NumPy, ffmpeg는 libvpx-vp9 알파 디코더가 필요하다. 첫 명령의 현재 경고 2개는 위에 명시한 원본 보존 건이다. 회귀 테스트 3개는 같은 프레임 수·재생 시간을 유지한 포즈 교환과 잘못된 hold를 검출하고, repeats와 작은 압축 오차를 허용한다.

포즈 순서는 모든 영상 틱을 96px의 premultiplied RGBA로 비교한다. 예상 포즈보다 다른 포즈가 평균 채널 오차 0.002 이상 더 가까우면 경고하며, 절대 오차 0.03 초과도 경고한다. 손실 압축 오차 내에서 구분 불가능한 유사 포즈의 정확한 순서를 입증하는 방법은 아니다. 원본 PNG의 바이트 검증, 영상 타임스탬프와 기존 육안 검수를 함께 사용한다.

검수 대상은 이 브랜치와 생성된 로컬 Pages 배포본이다. 원격 GitHub Pages 반영 확인과 OBS 앱 자체의 실제 방송 환경 성능 측정은 이 결과에 포함하지 않는다.
