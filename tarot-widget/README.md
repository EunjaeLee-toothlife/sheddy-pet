# 레몬 타로 방송 위젯

승인된 메이저 22장과 완드·성배·검·동전 각 14장을 사용하는 정적 위젯이다. 고전 금박 앞면·공통 뒷면과 기존 레이어 움직임을 사용한다. 별도 서버나 계정 없이 GitHub Pages와 OBS 브라우저 소스에서 실행한다.

## OBS 설정

Pages 게시 후 주소는 `https://eunjaelee-toothlife.github.io/sheddy-pet/tarot-widget/`이다. 이 주소는 배포본이 `master`에 반영되고 Pages 게시가 끝난 뒤 사용할 수 있다.

1. OBS에 **브라우저** 소스를 추가하고 위 주소를 입력한다.
2. 소스 크기를 **1200 × 900**으로 설정한다. URL에 `preview=1`을 넣지 않는다. 녹색 타로 테이블 바깥은 투명하며, 테이블 안쪽에는 읽기 쉬운 어두운 배경이 표시된다.
3. 소스의 **변환 → 변환 편집 → 하단 자르기**를 **225px**로 설정한다. 남는 방송 영역은 **1200 × 675**이다. ‘자르기/패딩’ 필터 대신 장면의 변환 자르기를 사용한다.
4. 소스 우클릭 → **상호작용**에서 위쪽 카드와 아래쪽 패널을 클릭한다. 조작 패널은 잘라낸 하단에 있으므로 송출되지 않는다.
5. ‘소스가 보이지 않을 때 종료’, ‘장면이 활성화될 때 브라우저 새로고침’은 끈 상태를 권장한다. 진행 상태는 같은 OBS 브라우저 저장소에서 복원된다.

창의 스크롤 위치를 바꾸면 송출 화면에도 영향을 준다. 1200 × 900 설정에서는 전체 위젯이 한 화면에 들어가며, 패널에 추가 알림이 많을 때만 패널 내부에서 스크롤된다. 일반 브라우저에서도 최대 너비 1200px로 표시한다.

## 점보기 흐름

- **One Card Spread / Three Card Spread**를 선택한다.
- 전체 78장을 섞어 **6개 덱 × 13장**으로 나눈다.
- 덱 하나를 선택하고, 나열된 카드 중 한 장을 선택한다. 서브덱에는 번호만 표시하고 수량은 숨긴다. 선택 전에는 카드 이름이나 앞면 그림을 표시하지 않는다.
- 세 장 모드에서는 선택한 카드를 제외하고 남은 전체 덱을 다시 섞는다. 77장은 `13·13·13·13·13·12`, 76장은 `13·13·13·13·12·12`로 나눈다. 뽑은 카드가 다시 나오지 않는다.
- 세 더미를 포개는 셔플, 여섯 덱과 선택한 덱의 카드를 차례로 펼치는 움직임, 뽑은 카드를 보관 위치에 놓는 연출이 이어진다. 연출 중에는 중복 선택을 막으며 ‘연출 건너뛰기’로 즉시 진행할 수 있다. 테이블과 카드 틀은 반복해서 흔들거나 반짝이지 않는다.
- 선택이 끝나면 카드 또는 하단의 공개 버튼을 눌러 **원하는 순서로 한 장씩 공개**한다. 카드는 제자리에서 약 0.56초 동안 옆으로 뒤집혀 정방향 앞면을 보여준다. 원화와 모든 상징 레이어를 함께 표시하며, 그림 준비가 끝난 뒤 연출을 시작한다. 공개된 그림의 호흡·깜빡임 등은 반복된다. 움직임을 끄면 즉시 공개한다.
- 공개한 카드를 다시 누르면 크게 볼 수 있다. 다른 카드는 작은 크기로 남으며, ‘전체 카드 보기’나 `Esc`로 돌아온다. 확대해도 카드의 상징과 원화 레이어 배치는 유지된다.
- 해석은 스트리머가 직접 진행한다. 세 자리의 의미는 고정하지 않는다.

하단 패널에서 표시 이름/질문을 적용하거나, 움직임을 멈추거나, 방송 영역을 숨길 수 있다. 움직임 정지는 추첨 연출과 반복 모션을 함께 멈춘다. ‘새 점보기’는 진행 중이면 한 번 더 눌러 초기화한다. 모두 공개한 뒤에는 한 번에 새 점보기를 시작한다. ‘덱 다시 선택’은 현재 섞인 상태를 유지한다.

효과음은 기본적으로 꺼져 있다. 켜면 덱과 카드를 다룰 때 짧은 종이 마찰음이 재생된다. 방송에 포함하려면 OBS 브라우저 소스에서 오디오를 OBS로 제어하도록 설정하고 오디오 믹서의 음량을 조절한다.

상호작용 창에서 숫자 `1`–`6`은 덱 선택, 읽기 단계의 `1`–`3`은 해당 카드 공개다. 카드 선택 단계에서는 방향키·`Home`·`End`로 이동하고 `Enter`로 선택한다. 연출 중 `Space` 또는 `Esc`는 연출만 건너뛴다. 이름/질문을 입력할 때는 이 단축키가 작동하지 않는다.

## 중간 저장

모든 선택·공개·표시 설정을 변경할 때 브라우저 `localStorage`에 먼저 저장한다. 추첨 연출 중에 새로고침해도 저장된 선택 결과를 이어간다. 확대 위치와 효과음 설정도 같은 브라우저에서 복원된다. 새로고침이나 OBS 재실행 후 같은 주소의 저장소가 유지되면 이어서 진행한다. 브라우저와 OBS의 저장소는 각각 별개이며 외부 브라우저에서 조작해 OBS를 제어하는 방식은 지원하지 않는다.

저장이 차단되거나 상태가 손상되면 패널에 알림을 표시한다. OBS 캐시/저장소 삭제, 다른 컴퓨터로 이동, 전원 장애로 브라우저 저장소 자체가 유실된 상황까지 보장하지 않는다. 표시 이름과 질문은 해당 브라우저에만 저장되며 서버로 보내지 않는다.

## 개발과 Pages 배포본 생성

저장소 루트에서:

```powershell
node tools/build_tarot_widget.cjs
python -m http.server 8474
```

로컬 미리보기: `http://127.0.0.1:8474/tarot-widget/?preview=1` — 녹색 배경은 미리보기 옵션이며 실제 OBS 주소에서는 빼야 한다.

```powershell
node tools/build_tarot_widget.cjs --pages
node tools/check_tarot_widget.cjs
node tools/check_tarot_widget.cjs --pages
node tools/check_tarot_salon.cjs --pages
node tools/check_tarot_salon.cjs --pages --width=800
node tools/record_tarot_motion.cjs --pages
node tools/check_tarot_widget_assets.cjs
node tools/widget_check.js
```

Pages 빌드에는 `sharp`, 위젯 브라우저 검수에는 `playwright`와 Chrome이 필요하다. 살롱 검수는 실제 프레임 변화와 복원을 검사하고 동영상을 남긴다. 동영상 기록에는 `playwright install ffmpeg`로 설치한 Playwright용 FFmpeg가 필요하다. 기존 Electron의 `package.json`은 변경하지 않는다. 빌더는 `docs/`를 직접 생성하며, 코드와 함께 생성물을 커밋하고 브랜치 → PR로 `master`에 반영한다. 기존 펫의 `docs/index.html`은 보존한다.

빌드 시 승인된 카드 데이터 5개 파일을 합치고, 사용 중인 원화·깜빡임·배경·상징 레이어만 복사한다. PNG는 **무손실 WebP**로 압축하며 그림과 알파를 유지한다. `docs/tarot-widget/build-manifest.json`에 원본 해시와 파일 크기를 기록한다. 별도의 이미지 생성이나 재배치는 하지 않는다.

주요 파일: `game.js`는 추첨 규칙과 상태 검증, `cards.js`는 승인된 레이어 조립, `widget.js`는 화면과 저장, `show.js`는 취소 가능한 추첨 연출과 효과음, `widget.css`는 기본 방송/조작 영역, `salon.css`는 타로 테이블 디자인이다. `deck.json`은 빌더가 생성하므로 카드 변경은 원래 `tarot-study/*-data.js`에서 한다.
