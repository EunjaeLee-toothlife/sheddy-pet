## Reconstruction workflow

1. Read the source PNGs, actual pose plans/descriptions, original duration, holds/repeats and runtime rate from the ledger. Resolve description-count or side-label mistakes against the actual original images; do not silently drop an action.
2. Prepare a maximum four-pose 2×2 input, inspect it, then use **Codex built-in ImageGen** with the canonical clean reference. Sharp individual keyposes or full-resolution 2×2 batches replace the earlier soft large-sheet approach. Require each complete character/effect to stay inside its own cell with green margins. Use opaque green for this project to avoid the speckled matte observed in the early direct-alpha experiment.
3. Save the exact prompt under `prompts/rebuild/` and copy each project generation into `sprites/rebuilt/raw_poses/` or `sheets/`. Keep raw donors and registration plans for reproducibility.
4. Key and stage the poses, preserving reviewed disconnected effects. Protect intentional enclosed green in food/liquid with a reviewed bounded region; do not clamp every green pixel. Register by planted shoes/body anatomy rather than total silhouette height, so raised arms, jumps, crouches, turns and props are not normalized away.
5. Encode with original frame slots, holds/repeats, derived FPS and playback rates. Audit original hashes, exact PNG/video hashes, 512RGBA, duration, expanded ticks, actual libvpx-vp9 decoded alpha and canvas clipping.
6. Compare all source/candidate poses and actual playback for gestures, outcomes, clothing changes, stable anatomy/outlines/colors and clean face/coat interiors. Inspect internal loop closure and joined start/loop/end/outro boundaries. Revise failing poses before marking the relevant flags.
7. Root imports only validated worker-owned clips. After every final flag passes, record reviewed status, integrate rebuilt runtime/Pages assets, then verify the selected final paths and hashes. Import or generation count is not approval.

Workers used isolated `anims/rebuild_worker_<name>.json` ledgers with explicit `--manifest`; only root updates the central ledger. Groups were dance, pastry, pastry_extra and special, with root owning final integration and review. Shared tools and originals are not edited by isolated workers without coordination.

```powershell
python tools/rebuild_frame_batches.py prepare <clip> --indices 0 1 2 3 --manifest anims/rebuild_worker_<name>.json
# After inspecting the input and using built-in ImageGen:
python tools/rebuild_frame_batches.py ingest <clip> --indices 0 1 2 3 --source <generated.png> --keep-components --manifest anims/rebuild_worker_<name>.json
python tools/rebuild_animations.py encode <clip> --manifest anims/rebuild_worker_<name>.json
python tools/rebuild_animations.py audit <clip> --manifest anims/rebuild_worker_<name>.json
# Root imports audited owned clips; staged partial clips are excluded.
python tools/merge_rebuild_workers.py dance pastry pastry_extra special
```
